# v2.4.8

**Each faction's own unit card in the Unit Editor, and the ones borrowed from
another faction marked.**

## New

* **Each faction's own card, grouped by faction.** With the Unit Editor's list
  grouped by faction, every tile now shows that faction's own unit card, from
  its own folder under `data/ui/units/`, where before every tile showed the
  same one. Where a faction has no card of its own and the game would show
  another's, the tile says *borrowed* and takes a dashed outline. A
  **borrowed cards** checkbox beside *mercs* keeps only those, so the cards a
  mod is still missing are one click away. A unit with no card anywhere is
  not marked. A suggestion from a player on Discord.
